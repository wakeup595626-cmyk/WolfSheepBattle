## 1. 四项问题的原因与修复

### 1.1 浅色正式 UI 上的文字不清晰/越界

原因：

1. 多数 Label 创建于代码占位阶段，颜色按深蓝黑 Graphics 背景设置为白色或浅蓝灰；正式羊皮纸/浅绿色贴图覆盖后，Label 颜色没有同步切换。
2. 资源框、单位卡和战术牌 Label 沿用接近父节点全宽的尺寸，未给图标区和边框预留稳定内边距。
3. 战术牌虽然已有标题/状态两个 Label，但文本区域左边界侵入图标区，且未明确关闭换行/设置 SHRINK。
4. 禁用态直接大幅压暗正式卡图，文字也同步变浅，造成“双重降对比”。

修复：

- 建立复用方法 `configureSingleLineLabel()` 与 `resizeAndPositionLabel()`。
- 正式浅色 UI 的主文字统一为 `#563A25`，说明文字统一为 `#6B6256`，玩家补给数值使用墨绿色 `#345B3E`。
- 目标单行 Label 全部使用 `Label.Overflow.SHRINK`、`enableWrapText=false`、垂直居中；标题/说明保持独立 Label。
- 先调整 UITransform、锚点区域和内边距，再由 SHRINK 处理极端长度，没有用异常小字号掩盖越界。
- 禁用单位卡只轻度降低贴图亮度，文字仍保持深色；禁用战术牌标题/说明仍保持主/次深色。
- 基地血条仍保留白字和现有深色阴影，不改变血条逻辑。

### 1.2 “战术”标题仍是深蓝黑占位框

原因：`TacticSidebarHeader` 只有 Graphics，没有绑定正式资源；三张战术牌已经切换到正式图片，标题栏却仍使用旧科技感深色填充。

修复：

- 复用 `art_ui` 中现有 `NoticeBanner` 羊皮纸资源，没有增加新图片。
- 标题栏正式尺寸为 `200 × 36`，与下方三张战术牌同宽。
- 标题栏位置保持 `(528, 232)`，第一张卡位置保持 `(528, 159)`；标题栏底部到第一张卡顶部约 12 设计像素。
- 正式资源加载成功后关闭标题栏 Graphics；资源失败时才保留原 Graphics 回退。
- 标题使用 `#563A25`、20 px、176×24 安全文本区。
- 正式战术牌使用图片内原生图标，隐藏重复的代码图标框；标题/说明区域调整为 x=30、宽112，避免覆盖左侧图标。
- 战术功能、费用、解锁、冷却和点击区域未改变。

### 1.3 右上角暂停按钮被压扁

原因：暂停正式图标原图为 `128 × 128` 的圆形资源，旧代码把它直接放进 `200 × 34` 区域，发生严重非等比横向拉伸；同时父按钮高度只有34，触摸与视觉都偏薄。

修复：

- 父按钮改为 `180 × 54`，位置 `(538, 308)`，右边缘仍为628，与右侧功能栏对齐并保留12设计像素安全边距。
- 复用 `ButtonSecondary` 作为 `180 × 54` 正式按钮底图，其原始宽高比约3.33，与180:54一致。
- 圆形暂停图标改为 `38 × 38`，位置 `(-62, 0)`，保持1:1显示。
- 父节点、背景、图标的 scale 均保持 `(1, 1, 1)`。
- “Ⅱ 暂停”位于 `(23, 0)` 的 `110 × 40` 文本区，18 px、`#563A25`、水平/垂直居中。
- 触控区域与完整 `180 × 54` 父按钮一致；暂停功能和 Modal 层级未改变。

### 1.4 中央出兵提示条双背景、浅字、位置过高

原因：

1. `StatusToast` 旧 Graphics 为 `440 × 32`，正式 NoticeBanner 为 `420 × 44`，两个背景同时渲染且尺寸不一致，黑框从羊皮纸两侧露出。
2. 文本仍是为黑底设置的浅色，正式羊皮纸上对比不足。
3. 原位置 `(0, 226)` 位于战场上部，遮挡中央战斗。
4. 旧动画没有淡入阶段，连续消息只重启透明度倒计时，视觉更新偏突兀。

修复：

- `StatusToast` 继续只创建一次并复用；新消息只更新文本并停止/重启同一组 Tween，不创建重复节点。
- 正式提示背景、父节点和文字统一中心锚点。
- 正式尺寸：父节点/羊皮纸 `540 × 60`；Label `492 × 48`，左右各24设计像素安全边距。
- 正式位置：`(-90, -184)`，即玩家 HUD 中心线 `y=-284` 上方100设计像素，位于战场中下部。
- 文本使用22 px、`#563A25`、单行居中；格式为“第1线派出小羊 · 消耗12能量”。
- 正式 NoticeBanner 成功加载时 `StatusToast` 的旧 Graphics 明确 `enabled=false`；只有正式资源失败时才使用黑色 Graphics 回退。
- 动画时序：0.15秒淡入、1.2秒停留、0.2秒淡出。
- 暂停时立即停止提示 Tween 并隐藏提示；ModalLayer sibling index 2，高于 HudLayer 的1，提示不会穿透暂停面板。
