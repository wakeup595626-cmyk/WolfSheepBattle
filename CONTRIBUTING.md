# Contributing

English | [中文](CONTRIBUTING.zh.md)

Thank you for your interest in WolfSheepBattle!

## Ways to contribute

- **Report a bug**  open a [GitHub Issue](https://github.com/wakeup595626-cmyk/WolfSheepBattle/issues) with your Cocos Creator and WeChat DevTools versions, reproduction steps and what you expected.
- **Suggest a balance or level change**  please describe the gameplay problem you observed, not only the numbers you would change.
- **Improve the docs**  the README exists in English and Chinese; corrections to either side are welcome.

## Development

1. Install **Cocos Creator 3.8.8**.
2. Clone this repository and open the folder in Cocos Creator.
3. Open `assets/scenes/Battle.scene` and use the editor's preview.

Build outputs (`library/`, `temp/`, `build/`) are regenerated locally and are intentionally not tracked.

## Pull requests

- Keep each pull request focused on one change.
- Do not commit `library/`, `temp/`, `build/` or `profiles/`.
- Update both `README.md` and `README.zh.md` if documented behaviour changes.
- If you add third-party assets, document them (fonts in `THIRD_PARTY_LICENSES/`, audio in `THIRD_PARTY_AUDIO.md`).
